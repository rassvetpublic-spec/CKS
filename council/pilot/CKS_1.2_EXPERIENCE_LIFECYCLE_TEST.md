# CKS 1.2 Experience Lifecycle Test

## Purpose

Verify that experiments and lessons learned are stored separately from canon knowledge.

## Lifecycle

Experiment -> Observation -> Outcome -> Lesson -> Future Reference

## PASS criteria

- experiment context preserved
- outcome preserved
- lesson preserved
- experience is not automatically knowledge
- provenance remains available

## Constraints

- no runtime storage
- no execution queue
- no automatic canon update
- Human Gate required for architectural changes
