# CKS Memory Pack — пилот на двух беседах

Это компактный пакет проверяемого контекста. Полные беседы и память агента не сохраняются.

| Файл | Назначение |
|---|---|
| [CKS Bootstrap Context.md](CKS%20Bootstrap%20Context.md) | Единый вход для нового чата |
| [SOURCES.md](SOURCES.md) | Источники, сообщения и ограничения проверки |
| [QA_HISTORY.md](QA_HISTORY.md) | Извлечённая история проверок |
| [NEW_WORK_CHAT.md](NEW_WORK_CHAT.md) | Готовый запрос новому исполнителю |
| [decision-candidate.yaml](decision-candidate.yaml) | Кандидат по существующей схеме CKS |

Пилот выполнен как извлечение и сверка существующего материала. Новые задания
в исходные чаты не отправлялись; независимого нового QA-раунда не было.
Результат: основания больше не зависят от пересказа полной беседы,
а расхождения стали явными. Автоматический handsfree-цикл ещё не проверен.

Файлы должны версионироваться вместе с Council после обычной проверки изменений.
Для переноса пакета в другой чат достаточно приложить Bootstrap Context;
при отсутствии доступа к Git приложите также SOURCES и QA_HISTORY.
