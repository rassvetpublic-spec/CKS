# CKS 1.2 Decision Memory Lifecycle Test

## Purpose

Verify that decisions can be preserved with rationale and evidence without becoming active knowledge automatically.

## Lifecycle

Proposal -> Review -> Evidence Check -> Decision -> Accepted or Rejected History

## PASS criteria

- decision identity preserved
- rationale preserved
- evidence references preserved
- rejected decisions remain searchable
- rejected decisions do not enter active knowledge
- no automatic promotion to canon

## Constraints

- CORE is unchanged
- no Owner field
- no Task ID
- no runtime state
- Human Gate required for acceptance
