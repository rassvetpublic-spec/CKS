# CKS 1.2 Lifecycle Test Matrix

Status: Discovery Draft

## Knowledge acceptance

Checks:

- source exists;
- evidence exists;
- review completed;
- provenance preserved;
- no silent canon update.

## Decision lifecycle

Checks:

- alternatives preserved;
- rationale preserved;
- evidence linked;
- lifecycle status valid.

## Graveyard lifecycle

Checks:

- rejected object preserved;
- rejection reason preserved;
- object excluded from active knowledge;
- controlled resurrection only.

## Boundary checks

Reject:

- owner fields in knowledge objects;
- task execution state in knowledge;
- hidden memory dumps as evidence.
