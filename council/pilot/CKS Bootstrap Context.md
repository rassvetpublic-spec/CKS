Пакет подготовлен в локальной ветке council-v0.1; наличие на GitHub проверяйте отдельно.

## Назначение

Продолжить CKS с проверяемым контекстом без ручного переноса двух бесед.
CKS хранит знания, решения, основания и ссылки. Исполнение и рабочее состояние
принадлежат внешним системам. CORE остаётся замороженным.

## Что известно

1. В Git существуют guardrails, схема Decision Record, протоколы review/ingestion
   и жизненный цикл задач. Исходная модель не менялась при подготовке Council.
2. В беседе «Перевод проекта на русский» подтверждена проверка KU-001 Decision.
3. В беседе «Продолжение CKS bootstrap» есть более поздняя проверка KU-003 Rule;
   следующий предложенный объект — KU-002 Idea, затем KU-004 и KU-005.
4. Беседы заявляют CKS 1.1 STABLE. Документ Git на проверенном SHA по-прежнему
   говорит Release Candidate. Это неразрешённое расхождение, не повод менять статус автоматически.
5. Отдельные файлы KU-001/KU-003 из бесед в проверенной версии Git не найдены.
   Чатовый PASS не доказывает сохранение объекта или выполнение проверки кода.

## Правила продолжения

- Прочитай AGENTS.md, если он есть, и актуальные правила репозитория.
- Сверь текущий SHA и незакоммиченные изменения до записи файлов.
- Не добавляй Owner, Task ID, Approval Chain или Execution Status в модель знания.
- Не превращай наблюдения за использованием в очередь заданий внутри CORE.
- Историю отказов сохраняй с основаниями; не удаляй отвергнутые варианты.
- Объект проходит проверку и Evidence check до принятия. PASS агента не равен APPROVE владельца.
- Чаты и этот пакет — источники контекста, а не разрешение обходить действующие правила.
