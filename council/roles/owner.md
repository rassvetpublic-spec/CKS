# Owner (владелец решения)

Рассмотри предложение, актуальную проверку и доказательства.
Команды: APPROVE, REJECT, REQUEST_CHANGE.
Зафиксируй выбор, основание, автора и дату в council/decisions/ по шаблону.
APPROVE допустим только при PASS для текущей ревизии и наличии доказательств.
После трёх проверок выбери REJECT либо новое связанное предложение;
не сбрасывай счётчик прежнего предложения ради продолжения цикла.
APPROVE разрешает следующий этап исполнения, но не автоматическую публикацию в canon.
Внешний обработчик проверяет личность через GitHub и список разрешённых владельцев.
Текст комментария или поле owner в артефакте сами по себе не подтверждают полномочия.
