# Экономия токенов Council

## Что передаётся между ролями

Один пакет: цель, краткий контекст, изменения с прошлой ревизии, замечания,
до восьми ссылок и идентификаторы версии. Пример: `pilot/handoff.json`.
Лимиты в `.csk/context-budget.yaml`: 6500 символов на весь JSON-пакет,
1200 на резюме, 2500 на изменения, 1600 на замечания и 500 на цель.
Это проверяемые ограничения размера, а не обещание точного числа токенов.

```powershell
python scripts/check_council_packet.py council/pilot/handoff.json
```

Пакет сверх лимита отклоняется. Сократите область проверки или разделите задачу;
не обрезайте молча доказательства, риски или часть изменения.

## Правила работы

1. В новом чате один раз прочитать Bootstrap Context и актуальные правила.
   В следующих раундах передавать изменения; если исходного контекста нет,
   получить его заново по ссылкам. Ссылка сама по себе не даёт модели содержимое.
2. Reviewer читает изменённые места и необходимые зависимости. Полный аудит
   нужен при изменении архитектуры или недостаточности локальной проверки.
3. Ответ Reviewer: вердикт и до пяти главных замечаний с местом и исправлением,
   ориентир до 250 слов. Если проблем больше, явно указать неполноту и FAIL.
4. Ответ Architect: что исправлено по ID замечаний и ссылки на новую ревизию,
   ориентир до 350 слов. Не повторять весь документ.
5. Сначала выполнять обычные проверки конфигурации и тесты. Исправлять их
   ошибки до передачи задачи модели; в контекст включать краткий итог и ошибки.
6. Не более трёх QA-раундов. При повторяющемся споре передавать владельцу
   точный нерешённый вопрос и варианты, а не запускать длинный обмен заново.
7. Результат можно повторно использовать лишь для тех же repository/task/revision/SHA.
   После изменения головы PR или ревизии старый PASS недействителен.
8. Пакет Memory Pack загружать целиком только при необходимости. Обычный вход —
   Bootstrap Context; далее читать документы адресно по ссылкам.

## Учёт

Фактические input/output tokens и стоимость записывает внешний исполнитель,
если провайдер возвращает usage. Без таких данных записывать null, не оценку
как факт. Сравнение экономии делать на одинаковой задаче; процент заранее не заявлять.
Выбор модели и число параллельных исполнителей этот пакет не меняет.
