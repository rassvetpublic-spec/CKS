# Knowledge Cluster Model

## Clusters

- CORE — стабильные правила
- DOMAIN — предметные знания
- DECISION — решения
- EVIDENCE — доказательства
- PROCESS — процессы
- RESEARCH — исследования
- LEGACY — история
- EXPERIMENT — эксперименты

Cluster не определяет право изменения. Он определяет контекст хранения и анализа.
