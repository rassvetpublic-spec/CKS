# CKS 1.1 Scope

## Goal

Extend Bootstrap 1.0 with knowledge linking while preserving the minimal core.

## Included

- references between knowledge objects;
- basic relationship model;
- ADR references;
- traceability.

## Not included

- agents;
- autonomous promotion;
- knowledge graph platform;
- API runtime.

Principle:

Bootstrap stores knowledge. CKS 1.1 connects knowledge.
