# Antigravity Contract Validation v1

## Назначение

Минимальные правила проверки связи CKS, KAT9I_OS и Antigravity GUI.

## Проверки

PASS если:

- CKS не зависит от Electron;
- GUI получает только подтверждённые состояния;
- события соответствуют Event Contract;
- доказательства имеют источник;
- UI-состояние не считается каноном.

## FAIL если:

- GUI содержит бизнес-логику исполнения;
- UI изменяет знания CKS напрямую;
- worker обходится без Runtime слоя;
- решения создаются только на уровне интерфейса.

## Контрольный поток

```
GAP
 ↓
Evidence
 ↓
Proposal
 ↓
Decision
 ↓
Minimal Change
```

## Цель

Сохранить независимость CKS при развитии KAT9I_OS GUI.
