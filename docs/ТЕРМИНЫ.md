# Термины CKS v1.2

## Основные термины

| Термин | Простое описание |
|---|---|
| CKS (Context Knowledge System — система контекста и знаний) | Система управления знаниями, решениями и историей изменений |
| Core (ядро системы) | Неизменяемая базовая часть архитектуры |
| GAP (разрыв) | Подтверждённая проблема или недостаток текущего состояния |
| Evidence (доказательство) | Источник, подтверждающий необходимость изменения |
| Proposal (предложение) | Подготовленный вариант возможного изменения |
| Decision (решение) | Зафиксированный результат принятия решения |
| Canon (канон) | Материал, признанный официальной частью системы |
| Experiment (эксперимент) | Проверка идеи без статуса обязательного правила |
| Archive (архив) | Сохранённые исторические материалы |

## Правило терминологии

В документации CKS основной язык — русский.

Английский термин используется только при необходимости совместимости с кодом, именами файлов или международными понятиями. После первого использования указывается простая русская расшифровка.
