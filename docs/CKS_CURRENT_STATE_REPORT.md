# CKS Current State Report

## Текущая точка

CKS Bootstrap 1.0 завершён.
CKS 1.1 находится в статусе Release Candidate.
CKS 1.2 находится только на этапе анализа.

## Bootstrap 1.0

Состав:
- Repository (репозиторий)
- Knowledge Object (объект знания)
- Storage (хранилище объектов)
- Lifecycle (жизненный цикл)
- Validation (проверка)

## CKS 1.1

Состав:
- Reference (ссылка на объект знания)
- Relationships (связи)
- ADR Model (модель архитектурных решений)
- Decision Links (связи решений)
- Evidence Links (связи доказательств)
- Traceability (трассировка происхождения)

## Архитектурная граница

CKS хранит знания.
Внешние системы используют ссылки и проверенные артефакты.
CKS не является системой исполнения.
