# CKS Project Lifecycle Specification

## Purpose

Defines the lifecycle of CKS-managed work items.

## States

```text
BACKLOG
  ↓
ANALYSIS
  ↓
DESIGN
  ↓
IMPLEMENTATION
  ↓
QA
  ↓
ACCEPTED
  ↓
COMPLETED

GRAVEYARD_REVIEW
```

## Links

Project items may reference:

- Decision Records
- Knowledge Objects
- Evidence Records
- Issues
- Pull Requests

## Principle

A completed task is not automatically knowledge. Knowledge promotion requires review.
