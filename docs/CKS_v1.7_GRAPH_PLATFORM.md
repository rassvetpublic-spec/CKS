# CKS v1.7 Knowledge Graph Platform

## Goal
Create a persistent graph layer for CKS knowledge objects.

Principles:
- Graph is not SSOT.
- Graph is not decision authority.
- Graph provides relations, navigation and analysis.

## Components

Nodes
- knowledge objects
- evidence
- decisions
- protocols
- implementations

Edges
- supports
- derived_from
- depends_on
- supersedes
- conflicts_with
