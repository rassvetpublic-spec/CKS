# Изоляция Legacy (наследия) CKS v1.2

## Цель

Отделить исторические материалы от стабильной архитектуры CKS v1.2.

## Классификация

Материал считается Legacy, если он:

- относится к ранним экспериментам;
- описывает варианты, которые не были приняты;
- содержит идеи будущих расширений без решения;
- нужен для истории, но не для текущей работы.

## Граница

```text
CKS v1.2 Core
=
утверждённая архитектура

Legacy
=
история + эксперименты + отвергнутые варианты
```

## Правила

1. Legacy не является источником архитектурных решений.
2. Legacy не должен расширять Core.
3. Legacy может быть возвращён в рассмотрение только через GAP.

## Предлагаемая структура

```
legacy/
├── experiments/
├── rejected/
├── historical/
└── migrations/
```

После классификации каждый исторический материал получает статус:

- сохранён;
- заменён;
- отклонён;
- ожидает решения.
