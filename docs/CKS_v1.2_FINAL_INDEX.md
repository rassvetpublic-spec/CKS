# CKS v1.2 — финальный индекс документации

## Статус

```yaml
version: CKS_v1.2
status: archived
architecture: stable
core: frozen
development: gap_driven
```

## Назначение

Этот индекс фиксирует действующие слои CKS v1.2 и их границы.

## Core (ядро системы)

Назначение: действующая архитектура.

Правила:

- изменение только через GAP (выявленный разрыв);
- Proposal (предложение) не является Decision (решением);
- Experiment (эксперимент) не является Canon (каноном).

Основные документы:

- `core/CKS_OBJECT_MODEL.md`
- `core/CKS_LIFECYCLE.md`
- `core/CKS_CHANGE_RULES.md`

## Decision / Evidence слой

Назначение:

- хранение принятых решений;
- связь решений с доказательствами;
- история изменений.

Поток:

```text
GAP
↓
Evidence
↓
Proposal
↓
Decision
↓
Minimal Change
```

## Adapters (адаптеры)

Назначение:

- внешний обмен;
- преобразование форматов;
- интеграционные границы.

Ограничения:

- не изменяют Core напрямую;
- не создают Decision автоматически;
- не являются хранилищем знаний.

Документ:

- `core/ADAPTER_BOUNDARY_RULE.md`

## Legacy (наследие)

Назначение:

- исторические материалы;
- старые решения;
- завершённые эксперименты.

Legacy не является частью Core.

## Research (исследование)

Назначение:

- проверка новых идей;
- подготовка возможных GAP.

Исследования не получают статус архитектуры автоматически.

## GitHub слой

Назначение:

- задачи;
- проверки;
- автоматизация контроля.

GitHub Project и Issue не являются базой знаний CKS.

## Release состояние

```yaml
architecture: PASS
legacy_isolation: PASS
adapter_boundary: PASS
core_freeze: PASS
```

## Переход к CKS v1.3

Только через:

```text
новый GAP
↓
доказательство
↓
решение
↓
минимальное изменение
```

CKS v1.2 остаётся стабильной базовой точкой.
