# CKS v1.3 — стартовый шлюз

## Правило запуска

CKS v1.3 не является продолжением изменений v1.2 без основания.

Новый цикл начинается только при наличии:

```
GAP
↓
Evidence
↓
Proposal
↓
Decision
```

## Запрещено

- расширять Core без GAP;
- переносить Research в Canon автоматически;
- считать Issue решением;
- использовать Legacy как архитектурный источник.

## Разрешено

- создавать исследования;
- собирать доказательства;
- создавать предложения изменений.

## Начальная точка

CKS v1.2 остаётся стабильной базовой версией.
