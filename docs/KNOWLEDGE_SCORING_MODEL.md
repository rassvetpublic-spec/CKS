# CKS Knowledge Scoring Model v1

## Purpose

Оценка качества знаний перед продвижением в CKS.

## Score dimensions

- value: практическая ценность
- confidence: уверенность проверки
- evidence: количество и качество доказательств
- usage: повторное использование
- freshness: актуальность

## Lifecycle

Candidate -> Scored -> Validated -> Canon Ready

## Rule

Высокий score не заменяет Evidence и Decision Record.

Score помогает ранжировать объекты, но не создаёт канон автоматически.
