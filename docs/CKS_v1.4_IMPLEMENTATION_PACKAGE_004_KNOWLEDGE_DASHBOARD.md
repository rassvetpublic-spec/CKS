# CKS v1.4 IMPLEMENTATION PACKAGE 004 — Knowledge Dashboard

## Цель
Создать представление состояния базы знаний.

## Источники данных

- Knowledge Objects
- Metrics Reports
- Traceability Reports
- Review Gate Results

## Ограничения

Dashboard показывает состояние.
Dashboard не является источником истины.
Dashboard не изменяет знания.
