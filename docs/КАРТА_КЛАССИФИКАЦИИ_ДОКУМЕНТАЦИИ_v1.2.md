# Карта классификации документации CKS v1.2

## Назначение

Документ фиксирует разделение материалов репозитория CKS по статусу.

## Категории

| Категория | Назначение |
|---|---|
| Core (ядро системы) | действующая архитектура CKS v1.2 |
| Decision (решение) | утверждённые архитектурные решения |
| Evidence (доказательство) | материалы, подтверждающие решения |
| Legacy (наследие) | исторические материалы, старые варианты, архив |
| Research (исследование) | проверка идей без статуса решения |
| Example (пример) | демонстрационные материалы |

## Правила границ

- Legacy не является частью Core.
- Research не является каноном.
- Example не является архитектурным решением.
- Decision требует подтверждённого основания.

## Порядок изменений

GAP (выявленный разрыв)
→ Evidence (доказательство)
→ Proposal (предложение)
→ Decision (решение)
→ Minimal Change (минимальное изменение)

## Статус CKS v1.2

- архитектура: стабильная;
- ядро: заморожено;
- развитие: только через выявленные разрывы.
