# Правила документации CKS v1

## Назначение

Этот документ устанавливает правила написания новых документов CKS.

## Язык

Основной язык архитектурного описания — русский.

Английский используется только как технический слой совместимости.

## Формат термина

При первом использовании:

`English Term` (простое русское объяснение)

Пример:

`Reference` (ссылка на объект знания).

## Разрешено

- использовать английские имена файлов при необходимости совместимости;
- использовать английские поля YAML/JSON;
- использовать технические идентификаторы из кода.

## Запрещено

- менять технические идентификаторы на русский язык;
- использовать непояснённые английские термины в архитектурных документах;
- создавать разные переводы одного термина.

## Источник терминологии

Единый источник терминов:

`docs/ГЛОССАРИЙ.md`

Все новые документы должны соответствовать глоссарию.
