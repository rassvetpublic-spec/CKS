# CKS v1.3 Traceability Report Format

## Purpose
Machine-readable and human-readable validation output.

## Report fields

- object_id
- object_type
- validation_status
- missing_links
- evidence_state
- decision_state
- history_state

## Status values

PASS
WARN
FAIL

## Example

Object: CKS-DEC-001
Status: FAIL
Reason: missing evidence relation
