# Карта связей объектов CKS v1

## Назначение

Этот документ фиксирует связи между основными объектами CKS.

Цель: сделать восстановление контекста проверяемым.

## Базовая цепочка

```text
контекст (Context)
        ↓
предложение (Proposal)
        ↓
решение (Decision)
        ↓
доказательство (Evidence)
        ↓
изменение (Change)
        ↓
результат (Result)
        ↓
событие обучения (Learning Event)
        ↓
снимок состояния (Snapshot)
```

## Правила связности

- решение должно иметь основание;
- доказательство должно иметь источник;
- изменение должно ссылаться на решение;
- снимок состояния должен ссылаться на актуальные объекты.

## Текущий статус

Документ является картой модели и не заменяет существующие схемы объектов.
