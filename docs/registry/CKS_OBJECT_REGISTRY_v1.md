# CKS Object Registry v1

## Цель

Создать единый реестр объектов CKS.

## Текущие объекты для проверки

| Объект | Назначение |
|---|---|
| контекст (Context) | входная информация |
| решение (Decision) | принятое решение |
| доказательство (Evidence) | основание решения |
| артефакт (Artifact) | результат работы |
| объект выделенных знаний (Distillate) | результат обработки |
| снимок состояния (Snapshot) | восстановление состояния |

## Требуется дополнить

- путь файла;
- версию схемы;
- статус;
- связи;
- владельца.
