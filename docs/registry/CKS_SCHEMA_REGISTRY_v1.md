# CKS Schema Registry v1

## Назначение

Реестр схем объектов CKS.

Цель: зафиксировать существующие схемы, версии, расположение и статус совместимости.

## Правило

Не создавать новые схемы без проверки существующих.

## Реестр схем

| Схема | Версия | Путь | Статус | Назначение |
|---|---|---|---|---|
| решение (Decision Record) | v1 | schemas/ | активно | описание принятого решения |
| доказательство (Evidence Record) | v1 | schemas/ | активно | описание подтверждающих данных |
| пакет контекста (Context Package) | v1 | schemas/ | активно | перенос и границы контекста |
| договор артефакта (Artifact Contract) | v1 | schemas/ | активно | описание результата и условий |
| объект выделенных знаний (Distillate Object) | v1 | schemas/ | активно | результат выделения знаний |

## Правила совместимости

- изменение существующей схемы требует проверки влияния;
- новые версии должны сохранять историю изменений;
- устаревшие схемы не удаляются без решения.
