# Финальная карта состояния Issue CKS v1.2

## Назначение

Фиксация состояния открытых направлений после аудита CKS v1.2.

## Правила

Core (ядро системы) не изменяется без:

GAP (выявленный разрыв)
→ Evidence (доказательство)
→ Proposal (предложение)
→ Decision (решение)
→ Minimal Change (минимальное изменение)

## Состояние направлений

| Направление | Статус |
|---|---|
| CKS v1.2 closure | завершено |
| Legacy isolation (изоляция наследия) | в финальной проверке |
| Historical context migration (миграция исторического контекста) | отдельное направление |
| Research (исследования) | не являются Core |

## Ограничения

- Legacy (наследие) не является частью Core.
- Research (исследование) не является Canon (каноном).
- Example (пример) не является Decision (решением).
- Открытый Issue не означает изменение архитектуры.

## Следующий этап

Закрытие Legacy-аудита только после подтверждения классификации оставшихся материалов.
