# Antigravity Evidence Adapter v1

## Назначение

Слой адаптации доказательств между KAT9I_OS и GUI Antigravity.

## Граница ответственности

CKS является источником:

- контекста;
- знаний;
- решений;
- доказательств;
- истории изменений.

GUI только отображает подтверждённое состояние.

## Поток данных

```
CKS Evidence Layer
        ↓
KAT9I_OS Runtime
        ↓
Evidence Adapter
        ↓
Antigravity GUI
```

## Правила

1. GUI не создаёт доказательства.
2. GUI не изменяет канон CKS.
3. Любое отображение должно иметь источник состояния.
4. Evidence может быть показано только после проверки.

## Минимальная модель

```
Evidence
 ├── id
 ├── source
 ├── timestamp
 ├── status
 └── reference
```

## Связь QA

Поддерживается:

```
QA_CONTEXT = PR_HEAD + BASE_REFERENCE
```

для отображения проверяемого состояния в интерфейсе.
