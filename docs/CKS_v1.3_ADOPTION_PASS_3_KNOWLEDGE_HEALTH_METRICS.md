# CKS v1.3 ADOPTION PASS 3 — Knowledge Health Metrics

## Назначение

Определение метрик качества объектов знаний.

## Базовая модель

Knowledge Health = качество структуры + доказательность + актуальность + связность.

## Метрики

### Completeness Score

Проверяет наличие обязательных полей:

- id
- type
- owner
- lifecycle
- evidence
- history

### Evidence Score

Оценивает наличие и состояние доказательств.

### Freshness Score

Показывает актуальность объекта знаний.

### Consistency Score

Проверяет:

- корректность связей;
- отсутствие конфликтующих утверждений;
- соответствие Schema.

## Правило

Метрики являются сигналом качества и не заменяют Evidence или Decision.

## Интеграция

Knowledge Health может использоваться в Review Gate как диагностический слой.
