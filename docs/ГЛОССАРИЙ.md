# ГЛОССАРИЙ CKS v1.2

## Назначение

Единый источник терминологии CKS.

Правило: архитектурные объяснения пишутся на русском языке. Технические идентификаторы сохраняются на английском языке для совместимости.

## Основные термины

### Knowledge Object

Русское объяснение: объект знания.

Единица хранения знаний в CKS.

Использование:
- схемы данных;
- документы;
- хранилище объектов.

### Knowledge Runtime

Русское объяснение: рабочий контур знаний — программный слой, который нормализует объекты, строит индексы кластеров, тегов, статусов и проектов, а также создаёт динамические и Obsidian-представления.

Ограничение: рабочий контур знаний не является SSOT и не принимает архитектурных решений.

### Knowledge Intelligence

Русское объяснение: аналитика знаний — диагностический слой поиска скрытых связей, новых кластеров, развития знаний и проблем качества.

Ограничение: аналитика формирует предложения и сигналы, но не меняет Canon.

### Cluster

Русское объяснение: кластер — тематическая группа связанных объектов знаний.

Использование:
- навигация;
- группировка;
- аналитика скрытых связей;
- графическое представление.

### Tag

Русское объяснение: тег — лёгкий признак или фасет объекта знания.

Использование:
- фильтрация;
- поиск;
- динамические представления;
- предложение кластеров.

### Intuition Signal

Русское объяснение: сигнал интуиции — человеческое предположение о важности или скрытой связи, которое ещё не является доказательством.

Ограничение: интуиция ≠ Evidence и ≠ Decision.

### Dynamic View

Русское объяснение: динамическое представление — производная проекция базы знаний по статусам, кластерам, тегам, проектам, уверенности или другим признакам.

Ограничение: динамическое представление ≠ SSOT.

### Obsidian Vault

Русское объяснение: хранилище Obsidian — папка Markdown-файлов, открываемая приложением Obsidian как графическая и навигационная проекция знаний.

В CKS корень Git-репозитория может использоваться как Obsidian Vault без отдельного копирования базы.

### Reference

Русское объяснение: ссылка на объект знаний, а не копия самого знания.

Использование:
- связи между объектами;
- трассировка происхождения.

### Decision

Русское объяснение: запись принятого решения.

Использование:
- ADR;
- история архитектурных решений.

### Evidence

Русское объяснение: доказательство или источник подтверждения.

Использование:
- проверка происхождения знаний.

### Knowledge Graph Runtime

Русское объяснение: рабочий граф знаний — исполняемый слой, который хранит производное представление объектов знаний, связей и зависимостей между ними.

Использование:
- навигация по связям;
- анализ зависимостей;
- построение производного графа.

Ограничение: рабочий граф знаний не является SSOT (единым источником истины).

### Traceability Engine

Русское объяснение: движок трассируемости — механизм автоматического построения цепочек происхождения знания от источника и доказательства до решения, изменения и проверки.

Использование:
- проверка происхождения;
- поиск разрывов ссылок;
- объяснение причины существования знания или решения.

### Governance CI

Русское объяснение: непрерывная проверка правил управления CKS при каждом изменении репозитория.

Использование:
- проверка архитектурных границ;
- проверка SSOT;
- проверка трассируемости;
- запуск самопроверки.

Ограничение: Governance CI (непрерывная проверка управления) проверяет, но не принимает Decision (решение).

### Multi-project Knowledge Federation

Русское объяснение: федерация знаний нескольких проектов — производный индекс связей между независимыми CKS-проектами без объединения их канонов.

Использование:
- межпроектные зависимости;
- ссылки между объектами разных проектов;
- поиск общих и конфликтующих знаний.

Ограничение: Canon (канон) каждого проекта остаётся независимым.

### CKS Self Audit System

Русское объяснение: система самопроверки CKS — диагностический механизм проверки собственной архитектуры, управляющего слоя, трассируемости и рабочего контура.

Использование:
- поиск обязательных отсутствующих элементов;
- проверка контрактов состояния;
- проверка синтаксиса и базового исполнения рабочего контура.

Ограничение: самопроверка не изменяет Canon (канон) и не принимает Decision (решение).

### Runtime

Русское объяснение: рабочий исполняемый контур программных компонентов CKS.

Использование:
- выполнение графовых операций;
- построение трассируемости;
- формирование диагностических снимков.

### SSOT

Русское объяснение: единый источник истины — авторитетное место хранения утверждённого состояния конкретного типа знания или правила.

Использование:
- реестр источников истины;
- проверка авторитетности данных.

### Context Passport

Русское объяснение: паспорт контекста.

Использование:
- будущий слой описания происхождения внешнего контекста.

### Worker Manifest

Русское объяснение: описание возможностей рабочего агента.

Использование:
- будущий слой взаимодействия с исполнителями.

### Workflow

Русское объяснение: рабочий процесс.

Использование:
- GitHub Actions;
- автоматизация процессов.

### API

Русское объяснение: программный интерфейс взаимодействия систем.

Использование:
- внешние интеграции.

## Запрет

Не переводить технические идентификаторы в коде, YAML, JSON, API и GitHub Actions.
