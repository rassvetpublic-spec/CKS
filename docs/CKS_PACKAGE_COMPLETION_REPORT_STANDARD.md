# CKS Package Completion Report Standard

## Goal

Every enlarged package ends with one final report instead of many isolated confirmations.

## Required sections

### Identity

- Package ID
- Name
- Scope

### Work

What was completed.

### Verification

- tests;
- validation;
- review.

### Evidence

- commits;
- artifacts;
- read-back results.

### Remaining debt

Open architecture or process debt.

### Final state

PASS / PARTIAL / BLOCKED / CLOSED
