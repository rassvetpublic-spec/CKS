# CKS Package Completion Report Standard

## Назначение

Каждый укрупнённый пакет изменений завершается единым итоговым отчётом (Final Report) вместо множества изолированных промежуточных подтверждений.

## Обязательные разделы отчёта

### Identity (Идентификация пакета)

- Package ID — уникальный идентификатор пакета (например, `PACKAGE-001`);
- Name — краткое наименование пакета;
- Scope — границы и охват выполненных изменений.

### Work (Выполненная работа)

Описание фактически завершённых работ и реализованных изменений.

### Verification (Проверка)

Подтверждение корректности реализации:
- tests — результаты выполнения автоматических и юнит-тестов;
- validation — валидация схем, метаданных и CI-контрактов;
- review — архитектурный и экспертный контроль (Review Gate).

### Evidence (Доказательства)

Фактические свидетельства выполнения:
- commits — ссылки на зафиксированные коммиты;
- artifacts — ссылки на сгенерированные файлы и отчёты;
- read-back results — результаты контрольного считывания и верификации состояния.

### Remaining debt (Оставшийся долг)

Реестр открытого архитектурного, тестового или процессного долга. При отсутствии долга явно фиксируется отсутствие открытых обязательств.

### Final state (Итоговый статус)

Единый статус завершения пакета:
- PASS — пакет успешно завершён, все проверки пройдены;
- PARTIAL — пакет завершён частично, оставшийся объём зафиксирован как открытый долг;
- BLOCKED — завершение заблокировано внешними зависимостями или дефектами;
- CLOSED — пакет закрыт и включён в Canon/историю репозитория.
