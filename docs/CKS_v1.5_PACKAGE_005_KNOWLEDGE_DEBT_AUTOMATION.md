# CKS v1.5 PACKAGE 005 — Knowledge Debt Automation

## Назначение

Автоматическое выявление проблем качества знаний.

## Поток

```
Knowledge Object
      ↓
Health Metrics
      ↓
Debt Detection
      ↓
Review Queue
```

## Типы долга

- Evidence Debt;
- Freshness Debt;
- Traceability Debt;
- Ownership Debt;
- Consistency Debt.

## Ограничения

Debt Score не создаёт Decision и не изменяет Canon автоматически.
