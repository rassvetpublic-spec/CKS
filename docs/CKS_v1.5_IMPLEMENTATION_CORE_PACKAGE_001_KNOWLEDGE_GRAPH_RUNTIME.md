# CKS v1.5 Implementation Core Package 001 — Knowledge Graph Runtime

## Назначение
Рабочая модель графа объектов, связей и зависимостей.

## Принципы
- Граф не является SSOT (единственным источником истины).
- Граф хранит связи, историю и навигацию.
- Canon изменяется только через процесс решений.

## Объекты
- knowledge
- evidence
- decision
- architecture
- project

## Связи
- supports (поддерживает)
- derived_from (произведено из)
- depends_on (зависит от)
- supersedes (заменяет)
- conflicts_with (конфликтует)
