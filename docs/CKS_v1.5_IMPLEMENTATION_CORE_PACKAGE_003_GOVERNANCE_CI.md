# CKS v1.5 Implementation Core Package 003 — Governance CI

## Назначение
Проверка архитектуры при каждом изменении.

## Проверки
- Control Plane
- SSOT Registry (реестр источников истины)
- Traceability
- Lifecycle
- Canon boundaries

## Ограничение
CI проверяет состояние, но не заменяет архитектурное решение.
