# CKS — Canon Promotion Gate v1

## Назначение

Правила перевода изменений в канонический слой CKS.

## Поток

```
GAP
↓
Evidence
↓
Proposal
↓
Review
↓
Decision
↓
Minimal Change
↓
Canon
```

## Запреты

```
Proposal ≠ Canon
Draft ≠ Canon
Experiment ≠ Canon
Worker Report ≠ Canon
```

## Проверки перед Canon

- есть источник проблемы (GAP);
- есть доказательства (Evidence);
- есть решение (Decision);
- есть история изменений;
- изменение минимально;
- русский канонический документ обновлён.

## Статусы

- PLANNED
- REVIEW
- VERIFIED
- CANON
- REJECTED
