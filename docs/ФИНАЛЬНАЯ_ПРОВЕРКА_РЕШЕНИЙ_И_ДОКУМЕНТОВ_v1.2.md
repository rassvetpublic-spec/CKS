# Финальная проверка решений и документов CKS v1.2

## Назначение

Проверка границ между действующей архитектурой, решениями, доказательствами, исследованиями и наследием.

## Правила

- Core (ядро системы) изменяется только через подтверждённый GAP (выявленный разрыв).
- Proposal (предложение) не является Decision (решением).
- Experiment (эксперимент) не является Canon (каноном).
- Legacy (наследие) хранится для истории и анализа и не влияет на Core.

## Проверка документов

Каждый документ должен иметь один из статусов:

- Core (ядро системы);
- Decision (решение);
- Evidence (доказательство);
- Research (исследование);
- Example (пример);
- Legacy (наследие).

## Цепочка изменения

GAP (выявленный разрыв)

↓

Evidence (доказательство)

↓

Proposal (предложение)

↓

Decision (решение)

↓

Minimal Change (минимальное изменение)

## Итог

Архитектура CKS v1.2 считается стабильной.
Core заморожен.
Развитие выполняется только через управляемые разрывы и подтверждённые решения.
