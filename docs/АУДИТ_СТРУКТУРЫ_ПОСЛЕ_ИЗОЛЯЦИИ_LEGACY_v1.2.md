# Аудит структуры после изоляции Legacy CKS v1.2

## Статус

Версия: CKS_v1.2

Состояние:

- архитектура стабильна;
- ядро системы заморожено;
- развитие только через выявленные разрывы.

## Проверенная структура

| Область | Назначение | Статус |
|---|---|---|
| core | ядро системы | защищено |
| decisions | решения | требует доказательной цепочки |
| evidence | доказательства | источник подтверждений |
| docs | документация | управляемая область |
| examples | примеры и исследования | не являются ядром |
| graveyard | исторические материалы | изолировано |
| legacy | наследие | изолировано |

## Правила границ

Legacy (наследие) не является частью ядра.

Experiment (эксперимент) не становится Canon (каноном) автоматически.

Proposal (предложение) не является Decision (решением).

Изменение архитектуры проходит:

GAP (разрыв)
→ Evidence (доказательство)
→ Proposal (предложение)
→ Decision (решение)
→ Minimal Change (минимальное изменение)

## Результат

Структура подготовлена к дальнейшему развитию без расширения ядра без подтверждённой необходимости.
