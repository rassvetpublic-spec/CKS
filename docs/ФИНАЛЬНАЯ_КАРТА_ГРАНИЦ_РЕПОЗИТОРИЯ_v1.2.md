# Финальная карта границ репозитория CKS v1.2

Статус:

```yaml
version: CKS_v1.2
architecture: stable
core: frozen
development: gap_driven
```

## Назначение зон

| Зона | Назначение | Влияние на Core |
|---|---|---|
| Core (ядро системы) | утверждённая архитектура | является источником правил |
| Decision (решение) | принятые архитектурные решения | может изменять только через установленный процесс |
| Evidence (доказательство) | подтверждение решений | не меняет архитектуру |
| Documentation (документация) | описание системы | не является решением сама по себе |
| Example (пример) | демонстрация использования | не является частью Core |
| Research (исследование) | проверка идей | не является каноном |
| Legacy (наследие) | история и старые материалы | изолировано от Core |

## Правило изменений

Любое изменение архитектуры проходит цепочку:

```
GAP (выявленный разрыв)
↓
Evidence (доказательство)
↓
Proposal (предложение)
↓
Decision (решение)
↓
Minimal Change (минимальное изменение)
```

## Запрещено

- расширять Core без подтверждённого разрыва;
- превращать предложение в решение;
- превращать эксперимент в канон;
- использовать Legacy как источник обязательных правил.

## Итог

CKS v1.2 сохраняет стабильную архитектуру. Дальнейшее развитие выполняется только через управляемые изменения.
