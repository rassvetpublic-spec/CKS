# CKS HANDSOFF CONTRACT

## Назначение

HANDSOFF — единая точка восстановления CKS.

## Гарантии

- поиск локального репозитория;
- fallback через clone;
- проверка identity `rassvetpublic-spec/CKS`;
- восстановление `main` из `origin/main`;
- проверка ключевых якорей;
- поиск SSOT-кандидатов;
- финальный статус READY/BLOCKED.

## Режимы

```powershell
-Quiet  # минимальный вывод
-Repair # очистка поврежденного рабочего дерева
-E45    # дополнительная проверка E4.5
```

## Ограничения

HANDSOFF не является заменой CKS архитектуры. Он только восстанавливает доступ к каноническому состоянию.
