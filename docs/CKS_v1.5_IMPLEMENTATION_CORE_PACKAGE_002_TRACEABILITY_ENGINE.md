# CKS v1.5 Implementation Core Package 002 — Traceability Engine

## Назначение
Автоматическое построение цепочек происхождения знаний.

## Цепочка
Research (исследование)
→ Evidence (доказательство)
→ Knowledge Object (объект знания)
→ Decision (решение)
→ Change (изменение)
→ Review (проверка)

## Правило
Traceability показывает происхождение, но не принимает решения.
