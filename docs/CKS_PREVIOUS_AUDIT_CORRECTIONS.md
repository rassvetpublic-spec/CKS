# CKS — контроль предыдущих ошибок

## Найденные ошибки развития

### 1. Смешение архитектуры и планов

Исправление:

- отделять действующую архитектуру;
- отделять roadmap (план развития);
- отделять эксперименты.

### 2. Проект как главный объект

Исправление:

Проект является представлением графа знаний, а не контейнером файлов.

### 3. Недостаток статусов

Исправление:

Использовать жизненный цикл знания:

RAW → CAPTURED → CLUSTERED → UNDERSTOOD → CONNECTED → KNOWLEDGE → CANONICAL → EVOLVING.

### 4. Недостаток связности

Исправление:

Связи имеют историю и происхождение.

### 5. Языковое правило

Исправление:

Основной язык документации — русский. Технические термины допускаются с русским пояснением.

### 6. Obsidian

Исправление:

Использовать Markdown-объекты как совместимый слой визуализации графа, не заменяя ядро CKS.
