# CKS 1.1 Release

## Purpose

Move from isolated knowledge objects to traceable knowledge.

## Included

- References
- Relationships
- ADR model
- Decision links
- Evidence links

## Not included

- Agents
- Runtime execution
- Autonomous decisions
- Platform automation

## Principle

CKS stores knowledge and its origin. External systems may reference CKS but do not become the source of truth.
