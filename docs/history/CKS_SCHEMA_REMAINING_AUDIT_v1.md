# CKS Schema Remaining Audit v1

## Назначение

Продолжение аудита схем CKS после создания `CKS_SCHEMA_FIELD_AUDIT_v1.md`.

Цель:
- проверить оставшиеся объекты схем;
- зафиксировать их роль в модели CKS;
- подготовить связь с реестрами объектов и схем.

## Проверенные дополнительные схемы

| Схема | Назначение |
|---|---|
| `canon_registry_v1.yaml` | реестр канонических объектов |
| `decision_reference_v1.yaml` | связь решений с объектами |
| `exchange_message_v1.yaml` | обмен сообщениями между компонентами |
| `agent_task_v1.yaml` | описание задачи исполнителя |
| `agent_report_v1.yaml` | отчёт исполнителя |
| `audit_report_v1.yaml` | результат аудита |
| `candidate_object_v1.yaml` | кандидат на добавление объекта |

## Архитектурные выводы

Канон должен ссылаться на:
- решение;
- источник;
- доказательство;
- статус.

Связи решений должны сохранять:
- идентификатор решения;
- связанный объект;
- тип связи;
- описание.
