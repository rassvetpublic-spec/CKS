# CKS Removal Readiness v1

## Назначение

Проверка готовности к архивированию исходного рабочего чата после переноса знаний в CKS.

## Проверенные слои

| Область | Статус |
|---|---|
| архитектурные решения (ADR) | подтверждено |
| миграционная история | подтверждено |
| перенос аудита | подтверждено |
| архитектурное состояние | подтверждено |
| реестр объектов | создан и заполнен |
| реестр схем | создан и заполнен |
| карта связей объектов | создана |
| источник канона | описан |
| жизненный цикл объектов | создан |

## Проверенная связь канона

Канонический объект требует:

- идентификатор;
- источник;
- ссылку на решение;
- доказательство;
- статус.

Источник: `schemas/canon_registry_v1.yaml`.

## Проверенная связь решений

Связи решений поддерживаются через объект ссылки решения:

- решение;
- связанный объект;
- тип связи;
- описание.

Источник: `schemas/decision_reference_v1.yaml`.

## Жизненный цикл объектов

Добавлена модель состояний:

```text
Draft (черновик)
    ↓
Reviewed (проверено)
    ↓
Accepted (принято)
    ↓
Canonical (канонично)
    ↓
Deprecated (устарело)
```

Источник:

`docs/architecture/CKS_OBJECT_LIFECYCLE_v1.md`

## Ограничения

Перед дальнейшей автоматизацией требуется завершить:

- полный аудит полей YAML-схем;
- проверку связей объектов;
- заполнение текущего состояния системы.

## Точка продолжения

Следующий этап:

`schemas/*.yaml` → анализ полей → проверка связности → обновление реестров.
