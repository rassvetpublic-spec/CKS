# Context Split Modes

## Supported modes

### SPLIT
Break context into domains, clusters and artifacts.

### AUDIT
Analyze consistency, duplicates and risks.

### REVIEW
Review previous decisions against new evidence.

### RESEARCH
Create evidence-based proposals.

### MIGRATION
Transfer knowledge through validation.

### CLEANUP
Identify obsolete or duplicate objects.

### MERGE
Combine multiple knowledge sources.

### CANON CHECK
Validate compatibility with current rules.
