# CKS ↔ KAT9I_OS Adapter Contract v1

## Назначение

Документ фиксирует границу между системой знаний CKS и исполнительной системой KAT9I_OS.

## Принцип разделения

CKS отвечает:

- что требуется сделать;
- почему это требуется;
- какой результат считается успешным;
- какие доказательства нужны.

KAT9I_OS отвечает:

- кто выполняет;
- какими инструментами;
- каким процессом;
- в каком окружении.

## Запрет смешения слоёв

CKS не хранит исполнительные команды агентов как каноническое знание.

KAT9I_OS не меняет смысловые решения CKS без соответствующего процесса проверки.

## Контракт передачи

```yaml
contract: cks_kat9i_adapter_v1

input:
  task:
  context:
  constraints:
  evidence_required:

output:
  execution_result:
  evidence:
  status:
```

## Совместимость

Любая новая версия должна сохранять обратную совместимость или объявлять несовместимое изменение.
