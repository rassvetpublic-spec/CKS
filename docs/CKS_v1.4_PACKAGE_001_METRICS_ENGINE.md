# CKS v1.4 PACKAGE 001 — Metrics Engine

## Goal
Создание слоя расчёта состояния знаний.

## Components
- Knowledge Health Score
- Evidence Score
- Freshness Score
- Consistency Score
- Debt Score

## Rule
Metrics are diagnostic only. They do not create Canon decisions and are not SSOT.

## Flow
Knowledge Object → Metrics Engine → Health Report → Review Gate
