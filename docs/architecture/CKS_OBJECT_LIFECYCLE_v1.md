# CKS Object Lifecycle v1

## Назначение

Документ фиксирует жизненный цикл объектов CKS для восстановления контекста и дальнейшей проверки автоматизации.

## Общая модель

Объект CKS проходит состояния:

```
Draft (черновик)
    ↓
Reviewed (проверено)
    ↓
Accepted (принято)
    ↓
Canonical (канонично)
    ↓
Deprecated (устарело)
```

## Состояния

### Draft (черновик)

Новый объект или предложение.

Требования:

- есть источник;
- есть авторство или происхождение;
- не используется как правило.

### Reviewed (проверено)

Объект прошёл первичный аудит.

Требования:

- проверена структура;
- найдены связи;
- определены риски.

### Accepted (принято)

Решение принято для использования.

Требования:

- есть решение;
- есть доказательство;
- есть ссылка на основание.

### Canonical (канонично)

Объект является действующим источником правил CKS.

Требования:

- подтверждён источник;
- существует связь с решением;
- существует доказательство.

### Deprecated (устарело)

Объект больше не используется как актуальный.

Требования:

- сохранена история;
- указана причина изменения;
- есть ссылка на заменяющий объект при наличии.

## Правила переходов

```
Draft → Reviewed
```

Проверка структуры.

```
Reviewed → Accepted
```

Появление решения и доказательства.

```
Accepted → Canonical
```

Подтверждение канона.

```
Canonical → Deprecated
```

Замена или изменение правила.

## Ограничения

- история обсуждений не является каноном автоматически;
- внешний источник не изменяет канон напрямую;
- исполнительный слой не создаёт канон без процедуры принятия.
