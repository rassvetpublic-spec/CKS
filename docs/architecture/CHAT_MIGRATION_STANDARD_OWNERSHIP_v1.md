# Владелец стандарта переноса чатов

## Статус

Принятое архитектурное правило.

## Владелец

Владелец `CHAT_MIGRATION_STANDARD`:

```
CKS
```

Причина:

CKS отвечает за сохранение контекста, знаний, решений, доказательств и восстановление состояния.

## Потребители

```
KAT9I_OS
ReleaseHub
другие системы
```

Потребители могут применять стандарт, но не изменяют его смысл.

## Граница ответственности

```
CKS
 ├── что сохранять
 ├── как доказать сохранение
 ├── как восстановить контекст
 └── критерии успешного переноса

KAT9I_OS
 └── применение в рабочих процессах

ReleaseHub
 └── интеграция в процессы выпуска
```

## Правило

Стандарт переноса чатов является стандартом управления знаниями, а не стандартом исполнения.
