# Карта источников канона CKS v1

## Назначение

Документ фиксирует, где искать подтверждённые решения и правила CKS.

## Текущий порядок доверия

```text
архитектурное решение (ADR)
        ↓
принятое решение (Decision)
        ↓
подтверждающие материалы (Evidence)
        ↓
текущие правила и схемы
```

## Правила

- история обсуждений не является автоматически каноном;
- внешние идеи проходят проверку перед включением;
- исполнительные системы не изменяют канон CKS напрямую.

## Требует дальнейшего уточнения

Необходимо дополнить конкретными путями файлов:

- текущий реестр канона;
- активные решения;
- устаревшие варианты.

Статус: рабочий документ CKS v1.2.
