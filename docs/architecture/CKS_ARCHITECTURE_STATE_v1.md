# CKS Architecture State v1

## Назначение

Фиксация текущего понимания архитектуры CKS.

## Граница систем

CKS:
- контекст;
- знания;
- решения;
- доказательства;
- история изменений.

KAT9I_OS:
- исполнение;
- рабочие процессы;
- операционные действия.

## Принцип

Сначала понять существующую систему, затем изменять.

## Уровни

1. Архитектурные решения.
2. Объекты знаний и решений.
3. Процессы и автоматизация.

## Требуется проверить

- источник канона;
- связи объектов;
- реестр схем;
- жизненный цикл объектов.
