# Финальный контроль границ CKS v1.2

## Назначение

Документ фиксирует результат проверки границ после изоляции Legacy (наследия).

## Правила

- Core (ядро системы) содержит только утверждённую архитектуру.
- Legacy (наследие) хранит исторические материалы и не изменяет Core.
- Research (исследование) не является каноном.
- Example (пример) не является архитектурным решением.
- Proposal (предложение) не является Decision (решением).

## Изменение Core

Только через:

GAP (выявленный разрыв)
→ Evidence (доказательство)
→ Proposal (предложение)
→ Decision (решение)
→ Minimal Change (минимальное изменение)

## Статус

CKS v1.2:

- архитектура: стабильная;
- ядро: заморожено;
- развитие: только от подтверждённых разрывов.
