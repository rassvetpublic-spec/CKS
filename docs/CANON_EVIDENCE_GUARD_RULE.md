# Canon Evidence Guard Rule

## Purpose

Prevent Canon changes without evidence.

## Rule

Any object marked as Canon requires:

- Decision Record;
- Evidence Record;
- source reference;
- history of change.

## Forbidden

- Proposal as Canon;
- Experiment as Canon;
- Research document as Canon;
- automated Canon modification.

## Validation

Check:

Canon candidate
↓
Decision
↓
Evidence
↓
Review
↓
Activation
