# CKS Roadmap v1

## Bootstrap 1.0

Goal: CKS exists and stores knowledge.

Includes:

- repository foundation;
- minimal knowledge object;
- versioning;
- basic lifecycle;
- validation.

## CKS 1.1

Goal: CKS links knowledge.

Planned:

- references;
- related objects;
- ADR registry;
- decision relationships;
- improved search.

## CKS 1.2+

Goal: CKS becomes an integration platform.

Planned:

- context passport;
- worker manifest;
- APIs;
- adapters;
- agent exchange;
- advanced automation.

## Principle

Do not add platform complexity before the minimal knowledge lifecycle is proven.
