# Governance Runner Failure Cases

Документирует ожидаемые негативные сценарии Governance Runner. Это спецификация тестовых случаев, а не исполняемый тест.

1. Missing SSOT reference -> FAIL
2. Invalid lifecycle transition -> FAIL
3. Missing traceability chain -> FAIL
4. Validator warning -> WARN
5. Full validation -> PASS
