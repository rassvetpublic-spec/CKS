# Терминологический аудит CKS после ADR-007

## Цель

Проверить документацию CKS на соответствие языковой политике.

## Правила

- Русский язык используется для описания архитектуры, решений и требований.
- Английские термины сохраняются там, где они являются техническими идентификаторами.
- Каждый технический термин должен иметь русское объяснение.

## Проверяемые термины

| Термин | Использование | Русское объяснение |
|---|---|---|
| Knowledge Object | схема и модель данных | объект знания |
| Reference | связи объектов | ссылка на объект знания, а не копия |
| Decision | архитектурные решения | запись принятого решения |
| Evidence | подтверждение | источник или доказательство |
| Workflow | автоматизированный процесс | рабочий процесс |
| API | внешние интерфейсы | программный интерфейс |

## Правило изменений

Технические идентификаторы не переводятся ради читаемости.

Пример:

`decision_reference`

остается техническим именем.

В документации используется:

`Decision Reference (ссылка на решение)`.

## Результат

Документация CKS должна оставаться понятной человеку и совместимой с программными системами.
