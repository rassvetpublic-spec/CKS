# CHAT_MIGRATION_STANDARD_v1

## Назначение

Стандарт безопасного переноса важного чата перед удалением.

Цель:

> сохранить знания, решения и возможность продолжения работы без хранения всей истории чата.

---

# 1. Когда нужен перенос

Перенос требуется, если чат содержит:

- принятые решения;
- уникальные знания;
- важные файлы или ссылки;
- незавершённые задачи;
- архитектурные правила или ограничения.

Если чат не содержит ценности — допускается архивирование или удаление без переноса.

---

# 2. Что сохранять

Минимальный набор:

## Решения

Что принято и почему.

## Знания

Что стало известно и может использоваться дальше.

## Задачи

Что осталось сделать.

## Источники

Где проверить информацию.

## Bootstrap Snapshot

Как восстановить контекст в новом чате.

---

# 3. Пакет переноса

Минимальная структура:

```
CHAT_MIGRATION_PACKAGE/

SUMMARY.md
DECISIONS.md
TASKS.md
BOOTSTRAP.md
```

Полная история чата не является обязательным рабочим материалом.

---

# 4. Проверка восстановления

Перед удалением новый контекст должен определить:

1. Что это за проект.
2. Какие решения уже приняты.
3. Почему они приняты.
4. Что нельзя менять.
5. С чего продолжить работу.

Если восстановление не проходит — перенос считается незавершённым.

---

# 5. Удаление

Чат можно удалить после проверки:

- пакет переноса создан;
- источник сохранён;
- Bootstrap проверен;
- новый контекст восстановлен.

---

# Принцип

Не удалять историю напрямую.

Сначала выделить ценность:

```
чат
 ↓
аудит
 ↓
решения и знания
 ↓
Bootstrap
 ↓
проверка восстановления
 ↓
архивирование / удаление
```

---

# Связь с CKS

Этот стандарт является инструментом загрузки знаний в CKS.

Он не заменяет ядро CKS и не является источником канона.
