# CKS 1.2 Implementation Criteria

## Цель

Определить критерии начала реализации CKS 1.2.

## Обязательные критерии

### Архитектура

- границы ядра CKS определены;
- отсутствует смешение с исполнительными системами;
- сохранён принцип хранения знаний через объекты и ссылки.

### Зависимости

Каждый новый компонент должен иметь:

- назначение;
- владельца ответственности;
- список зависимостей;
- критерии отказа.

### Данные

Новые форматы должны:

- иметь версию;
- иметь схему;
- проходить проверку;
- не нарушать обратную совместимость.

## Не является критерием реализации

Само наличие технологии не является причиной создания компонента.

Не являются достаточными причинами:

- возможность создания API;
- возможность подключения агента;
- желание автоматизировать процесс без подтверждённой потребности.

## Правило перехода

CKS 1.2 начинается только для тех компонентов, которые доказали необходимость через реальные сценарии использования.
