# CKS Package Governance Model

## Назначение

Документ описывает управление укрупнёнными пакетами изменений.

## Принцип укрупнения

Связанные изменения выполняются как один пакет:

- цель;
- границы;
- решения;
- реализация;
- проверки;
- evidence (доказательства);
- итоговый отчёт.

## Жизненный цикл

IDEA

→ PACKAGE

→ EXECUTION

→ VERIFICATION

→ FINAL REPORT

→ CLOSED

## Правило завершения

Один укрупнённый пакет получает один итоговый статус завершения.

Контроль сохраняется через проверки и доказательства, а не через большое количество промежуточных подтверждений.
