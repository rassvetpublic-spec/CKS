# CKS Context Transfer Protocol

## Назначение

Передача рабочего состояния между чатами, агентами и исполнителями.

## Состав передачи

1. Current State (текущее состояние)
2. Decisions (решения)
3. Constraints (ограничения)
4. Open Debts (открытые долги)
5. Next Actions (следующие действия)
6. Evidence (доказательства)

## Правило

Новый исполнитель сначала проверяет состояние, затем выполняет работу.

Нельзя создавать новый источник истины без проверки существующего состояния CKS.
