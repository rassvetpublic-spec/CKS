# CKS 1.2 Discovery Blueprint

Status: DISCOVERY DRAFT

## Purpose

Define the next evolution layer without changing CKS CORE.

## Findings from CKS 1.1 tests

Confirmed capabilities:

- ingestion boundary protection
- evidence checks
- human gate protection
- merge protection

Discovered gap:

- rejected decisions need a verifiable lifecycle

## Proposed layers

### Knowledge Layer

Accepted knowledge only. Existing CKS principles remain unchanged.

### Decision Memory Layer

Stores accepted and rejected decisions with rationale, evidence and provenance.

### Experience Layer

Stores experiments, outcomes and lessons learned.

### Evolution Layer

Collects justified proposals for future architecture changes through Council.

## Rules

- CORE remains unchanged.
- Discovery items are not canon.
- Rejected items are not active knowledge.
- Rejection history must preserve rationale and evidence.
- No automatic promotion.

## Initial discovery inputs

- Graveyard lifecycle gap
- Council lifecycle validation
- Decision history requirements
