# Deferred Features

These features are intentionally postponed beyond Bootstrap 1.0.

## CKS 1.1+

- evidence enrichment;
- decision graph;
- object relationships;
- advanced knowledge discovery.

## CKS 1.2+

- context passport;
- worker manifest;
- agent protocols;
- runtime adapters;
- API layer.

## Experimental

- autonomous agents;
- knowledge graph visualization;
- automatic canon promotion;
- complex scoring systems.

## Rule

A deferred feature is not rejected. It is moved out of the foundation until the core lifecycle is proven.
