# CKS Evidence Model

## Назначение

Фиксация связи между изменением и подтверждением результата.

## Модель

ACTION

→ EVIDENCE (доказательство)

→ VERIFICATION (проверка)

→ STATE CHANGE (изменение состояния)

## Источники evidence

- commit;
- workflow result;
- тест;
- документ;
- read-back.

## Правило

Архитектурный долг считается закрытым только после наличия подтверждения.
