# CKS — Протокол консолидации знаний v1

## Назначение

Документ определяет объединение повторяющихся протоколов знаний без нарушения канонического слоя CKS.

## Принципы

- Knowledge ≠ Decision.
- Proposal ≠ Canon.
- Evidence требуется перед продвижением в Canon.
- Русский язык проекта является каноническим слоем.

## Процесс

```
Обнаружение дубля
↓
Сравнение объектов знаний
↓
Сохранение лучшего источника
↓
Перенос истории изменений
↓
Проверка Evidence
↓
Обновление Canon
```

## Запрещено

- удалять историю знаний;
- заменять Canon без проверки;
- создавать дублирующие канонические объекты.

## Проверка

Статусы:

- PLANNED
- REVIEW
- VERIFIED
- CANON
- REJECTED
