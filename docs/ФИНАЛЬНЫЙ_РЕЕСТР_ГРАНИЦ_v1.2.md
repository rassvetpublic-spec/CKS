# Финальный реестр границ CKS v1.2

## Назначение

Фиксация границ между рабочей архитектурой, историческими материалами и исследованиями.

## Классы материалов

| Класс | Назначение |
|---|---|
| Core (ядро системы) | утверждённая архитектура CKS v1.2 |
| Decision (решение) | принятые изменения |
| Evidence (доказательство) | подтверждающие материалы |
| Research (исследование) | проверка идей без статуса решения |
| Example (пример) | демонстрационные материалы |
| Legacy (наследие) | история, старые версии, отвергнутые варианты |

## Ограничения

Legacy (наследие) не является частью Core (ядра системы).

Research (исследование) не становится Canon (каноном) автоматически.

Proposal (предложение) не является Decision (решением).

## Изменение Core

Любое изменение ядра проходит цепочку:

GAP (выявленный разрыв)

→ Evidence (доказательство)

→ Proposal (предложение)

→ Decision (решение)

→ Minimal Change (минимальное изменение)
