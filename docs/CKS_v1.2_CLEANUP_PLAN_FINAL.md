# CKS v1.2 — финальный план очистки

## Назначение

Документ фиксирует безопасную очистку после стабилизации CKS v1.2.

Правило:

- Core (ядро системы) не удаляется.
- Удаление возможно только после проверки потери информации.
- Исторические материалы переводятся в Legacy (наследие), а не удаляются автоматически.

## Состояние

```yaml
version: CKS_v1.2
status: archived
architecture: stable
core: frozen
```

## Оставить без изменений

- core/*
- config/policies.yaml
- config/validation_rules.yaml
- README.md
- ARCHITECTURE.md
- .github/workflows/*
- .github/ISSUE_TEMPLATE/*

Причина: это действующие правила, границы и механизмы контроля.

## Перевести в Legacy после проверки

Кандидаты:

- старые версии адаптеров;
- исторические отчёты аудита;
- завершённые планы миграции;
- дублирующие статусные документы.

## Не удалять до отдельной проверки

- adapters/*
- docs/*
- examples/*
- research/*

## Найденные GAP

### GAP-01 Documentation duplication

Проблема:

Несколько документов описывают текущее состояние.

Решение:

Выделить один текущий статусный документ и сохранить историю отдельно.

### GAP-02 Adapter history

Проблема:

Старые версии адаптеров могут дублировать актуальные контракты.

Решение:

Проверить уникальность перед переносом.

### GAP-03 Config consistency

Проблема:

Конфигурация может изменяться быстрее документации.

Решение:

Добавить автоматическую проверку согласованности.

## Итоговое решение

Очистка выполняется только через:

GAP
↓
Evidence (доказательство)
↓
Proposal (предложение)
↓
Decision (решение)
↓
Change (изменение)

Автоматическое удаление файлов запрещено для Core и архитектурных документов.
