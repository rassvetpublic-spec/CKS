# CKS v1.2 — отчёт автономной очистки

## Цель

Провести безопасную очистку репозитория после стабилизации CKS v1.2 без нарушения правила Core Freeze.

## Выполнено

### Сохранены без изменений

- `core/` — ядро системы.
- `config/policies.yaml` — политики системы.
- `config/validation_rules.yaml` — правила проверки.
- `README.md`.
- `ARCHITECTURE.md`.
- `.github/workflows/` — автоматические проверки.
- `.github/ISSUE_TEMPLATE/` — шаблоны процессов.

Причина: эти элементы определяют архитектуру, правила и контроль изменений.

## Проверенные зоны

### Documentation

Статус: REVIEWED.

Потенциальные дубли статусных документов не удаляются автоматически. Требуется решение через Decision.

### Adapters

Статус: REVIEWED.

Старые версии адаптеров являются кандидатами на перенос в Legacy после проверки содержимого.

### Config

Статус: REVIEWED.

Контролируется риск расхождения документации и конфигурации.

## Запрещённые действия

- удаление Core;
- изменение архитектуры без GAP;
- перенос Research в Canon;
- превращение Legacy в действующие правила.

## Следующие безопасные действия

1. Проверка кандидатов на перенос в Legacy.
2. Создание Decision для удаления или объединения документов.
3. Проверка согласованности документации и конфигурации.
