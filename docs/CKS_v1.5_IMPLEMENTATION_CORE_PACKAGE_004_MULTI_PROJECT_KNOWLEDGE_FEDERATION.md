# CKS v1.5 Implementation Core Package 004 — Multi-project Knowledge Federation

## Назначение
Объединение нескольких CKS проектов через единый индекс связей.

## Принцип
Каждый проект сохраняет собственный Canon.

Federation Index (единый индекс связей) хранит:
- ссылки;
- зависимости;
- общие понятия;
- конфликты.

Federation не объединяет независимые источники истины автоматически.
