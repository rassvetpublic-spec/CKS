# Ownership Model Proposal

## Status

Proposal. Not Canon.

## Goal

Define ownership without mixing ownership and authority.

## Roles

- Knowledge Owner — отвечает за состояние объекта знания.
- Worker — выполняет действие.
- QA — проверяет результат.
- Authority — принимает разрешения.
- Project Controller — управляет рабочим состоянием.

## Rules

Ownership does not grant permission to change Canon.

Agent may:

- analyze;
- validate;
- propose.

Agent may not:

- create Canon;
- approve own decisions;
- bypass Evidence.

## Promotion path

Proposal
↓
Evidence
↓
Decision
↓
Implementation
