# CKS 1.2 Scope Review Checklist

## Статус

Только анализ. Реализация CKS 1.2 не начинается без отдельного архитектурного решения.

## Проверка кандидатов

### Context Passport

- Назначение: описание происхождения контекста и набора ссылок.
- Не является: копией знаний или хранилищем сырого контекста.
- Слой: метаданные и трассировка.
- Решение: отложить до подтверждённых сценариев.

### Worker Manifest

- Назначение: описание возможностей и ограничений внешнего рабочего агента.
- Не является: системой управления исполнителями.
- Слой: внешняя интеграция.
- Решение: отложить.

### External Adapter Contract

- Назначение: безопасный контракт обмена артефактами.
- Не является: переносом внешнего runtime внутрь CKS.
- Слой: интеграция.
- Решение: сначала определить требования.

### Import Pipeline

- Назначение: управляемый ввод проверенных артефактов.
- Не является: вторым источником истины.
- Слой: интеграция и проверка.
- Решение: отложить.

### Advanced Validation

- Назначение: расширение контроля качества знаний.
- Слой: потенциальное расширение ядра.
- Решение: требуется анализ реальных требований.

### Promotion Workflow

- Назначение: управление переходами статусов знаний.
- Не является: исполнительным процессом.
- Решение: не автоматизировать без отдельного ADR.

## Архитектурные ограничения

CKS:
- хранит знания;
- сохраняет происхождение;
- использует ссылки.

CKS не является:
- runtime;
- памятью агентов;
- системой исполнения;
- хранилищем сырых чатов.
