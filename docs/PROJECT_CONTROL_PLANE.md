# CKS Project Control Plane

## Purpose

Defines how CKS connects work items, decisions, evidence and lifecycle states.

## Lifecycle

BACKLOG
→ ANALYSIS
→ DESIGN
→ IMPLEMENTATION
→ QA
→ ACCEPTED
→ COMPLETED

GRAVEYARD_REVIEW remains available for rejected or obsolete approaches.

## Object Links

Issue
↓
Decision Record
↓
Evidence
↓
Implementation Artifact
↓
QA Result
↓
Canon or Completed State

## Principle

A completed task is not automatically accepted knowledge. Knowledge promotion requires validation.
