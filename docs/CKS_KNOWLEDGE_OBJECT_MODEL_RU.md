# CKS — модель объекта знания

## Назначение

Объект CKS — это не файл проекта, а единица знания, которая проходит жизненный цикл от сырого материала до проверенного знания.

## Жизненный цикл

```
RAW (сырой материал)
↓
CAPTURED (захвачено)
↓
CLUSTERED (сгруппировано)
↓
UNDERSTOOD (понято)
↓
CONNECTED (связано)
↓
KNOWLEDGE (знание)
↓
CANONICAL (каноническая основа)
↓
EVOLVING (развивается)
↓
ARCHIVED (архив)
```

## Поля объекта

```yaml
id:
name:
type:
version:
status:
clusters: []
tags: []
relations: []
evidence: []
traceability: []
confidence:
intuition:
```

## Представления

Один объект может иметь разные виды представления:

- по времени;
- по кластерам;
- по связям;
- по уверенности;
- по проектам;
- по проблемам.

## Правила

Граф знаний не является источником истины.

Метрики не являются решениями.

Автоматизация не изменяет канон без процесса решения.

Документация CKS пишется преимущественно на русском языке.
