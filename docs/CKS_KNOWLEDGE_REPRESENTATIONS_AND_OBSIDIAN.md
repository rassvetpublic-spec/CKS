# Представления знаний и Obsidian

Статус: архитектурно-реализационный документ производного представления. Не Canon сам по себе.

## Принцип

CKS не ограничивается видом Projects (проекты). Проект является одной из проекций графа знаний, а не контейнером файлов.

Obsidian используется как визуальный слой над CKS:

`объекты CKS → Markdown → wiki-ссылки → индексы → Canvas/Graph View`.

Obsidian не является SSOT (единым источником истины), не принимает решения и не переводит знания в Canon (канон).

## Поддерживаемые представления

- по времени;
- по кластерам;
- по тегам;
- по уверенности;
- по связности;
- по проблемам;
- по происхождению знаний;
- по статусам развития знания;
- по проектам-проекциям;
- графическое Canvas-представление связей.

## Структура Obsidian Vault

Производный экспорт создаёт структуру:

```text
CKS_Обзор.md
OBSIDIAN_CKS_README.md
Знания/
Кластеры/
Теги/
Проекты/
Статусы/
Карты/
  CKS_Граф.canvas
```

### Знания

Каждый объект CKS получает Markdown-заметку с YAML frontmatter (метаданными в начале файла), русским названием статуса, тегами, кластерами, проектами-проекциями, уверенностью и wiki-ссылками `[[...]]`.

### Кластеры, теги, проекты и статусы

Для каждого значения создаётся отдельная производная индексная заметка со ссылками на входящие объекты.

### Canvas

`Карты/CKS_Граф.canvas` строится из объектов и реальных связей CKS. Положение узлов ориентировано по движению знания от входного материала к знанию и канону. Canvas не является самостоятельной моделью данных: это производная графическая проекция.

## Реализация

Основной рабочий контур остаётся в `tools/cks_knowledge_runtime.py`.

Расширенный визуальный экспорт реализован в `tools/cks_obsidian_export.py`. Он повторно не реализует нормализацию, статусы или индексацию, а использует существующий `KnowledgeRuntime`.

Это важно для предотвращения двух расходящихся реализаций CKS.

## Русский режим

Человеческие названия, пояснения, навигация, документы и представления пишутся по-русски. Машинные идентификаторы и технические ключи могут оставаться английскими, если это необходимо для совместимости.

## Ограничения

- Obsidian ≠ SSOT.
- Canvas ≠ Canon.
- Wiki-ссылка ≠ доказательство.
- Тег ≠ статус.
- Кластер ≠ решение.
- Проект ≠ папка-источник истины.
- Изменение производной заметки не должно автоматически изменять исходный объект CKS.
