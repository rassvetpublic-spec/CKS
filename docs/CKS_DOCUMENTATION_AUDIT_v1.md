# CKS Documentation Audit v1

## Назначение

Проверка соответствия документации CKS архитектурным правилам и языковой политике ADR-007.

## Проверяемые принципы

- русский язык является основным языком описания архитектуры;
- английские термины используются как технические идентификаторы;
- каждый технический термин имеет объяснение в `ГЛОССАРИЙ.md`;
- идентификаторы схем, кода и API не переводятся.

## Области проверки

### Архитектура

Проверяется:

- разделение CKS и KAT9I_OS;
- отсутствие runtime-логики в CKS;
- отсутствие хранения необработанного контекста.

### Терминология

Проверяется:

- наличие определения английских терминов;
- единообразие терминов Reference, Decision, Evidence, Workflow, API;
- отсутствие параллельных переводов одного понятия.

### Документы

Проверяется:

- наличие назначения документа;
- описание области применения;
- указание ограничений;
- ссылки на связанные решения.

## Результат

Документация CKS должна оставаться понятной человеку и ИИ, сохраняя техническую совместимость с внешними системами.
