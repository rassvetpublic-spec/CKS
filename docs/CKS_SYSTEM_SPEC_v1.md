# CKS — Context Knowledge System

## Technical Specification v1.0

This document defines the system boundary and architecture of CKS.

## Core Principle

CKS is not a replacement for KAT9I_OS. CKS is an independent knowledge and decision management system compatible with KAT9I_OS through exchange protocols.

## System Boundaries

```
KAT9I_OS = execution system
CKS      = knowledge + decision system
GitHub   = collaboration + history layer
```

## Scope

- knowledge lifecycle
- decision records
- evidence management
- context splitting
- canon management
- graveyard management
- protocol-based integration
