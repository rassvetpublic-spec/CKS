# CKS 1.2 Decision Gate

## Назначение

Этот документ определяет условия перехода от анализа CKS 1.2 к реализации.

## Текущее состояние

- CKS Bootstrap 1.0 завершён.
- CKS 1.1 находится в состоянии Release Candidate.
- CKS 1.2 находится только на этапе анализа.

## Условия входа в реализацию

Реализация CKS 1.2 допускается только после:

1. подтверждения необходимости конкретного компонента;
2. определения границы между ядром CKS и внешней интеграцией;
3. описания зависимостей;
4. проверки отсутствия нарушения принципа независимости CKS.
