# Отчёт финальной проверки границ CKS v1.2

## Назначение

Фиксация результата проверки после изоляции Legacy (наследия).

## Правила

- Core (ядро системы) не расширяется без GAP (выявленного разрыва).
- Legacy (наследие) не является источником архитектурных решений.
- Research (исследование) не является каноном.
- Example (пример) не является решением.

## Проверенные категории

| Категория | Статус |
|---|---|
| Core | защищён |
| Decision (решение) | требует подтверждения через ADR (запись решения) |
| Evidence (доказательство) | используется для обоснования |
| Legacy | изолирован |
| Research | отделён от канона |
| Example | отделён от архитектуры |

## Порядок изменений

GAP (выявленный разрыв)

→ Evidence (доказательство)

→ Proposal (предложение)

→ Decision (решение)

→ Minimal Change (минимальное изменение)
