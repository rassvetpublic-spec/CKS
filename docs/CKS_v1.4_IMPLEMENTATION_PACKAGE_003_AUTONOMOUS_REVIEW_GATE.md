# CKS v1.4 IMPLEMENTATION PACKAGE 003 — Autonomous Review Gate

## Цель
Подготовить автоматизацию подготовки проверок изменений.

## Поток

Change
→ Evidence
→ Validation
→ Review Gate
→ Human decision

## Ограничения

Automation не принимает архитектурные решения.
Automation не создаёт Canon.
Automation формирует проверяемый контекст.
