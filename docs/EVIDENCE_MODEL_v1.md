# CKS Evidence Model v1

## Purpose

Evidence provides traceability for knowledge objects and decisions.

## Principle

Knowledge is not promoted by existence alone.

Flow:

Knowledge Object
↓
Decision
↓
Evidence
↓
Validated state

## Bootstrap compatibility

Evidence does not create knowledge automatically.
Evidence supports verification.

## Minimal fields

- id
- source
- description
- reference
- created_at
- status
