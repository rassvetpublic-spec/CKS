# Защита архитектуры CKS v1.2

## Назначение

Документ фиксирует защиту границ CKS v1.2.

## Правила замороженного ядра

```yaml
core:
  status: frozen

rules:
  no_core_expansion_without_gap: true
  no_proposal_as_decision: true
  no_experiment_as_canon: true
```

Расшифровка:

- расширение ядра без подтверждённого разрыва запрещено;
- предложение не является решением;
- эксперимент не является каноном.

## Запрещённые автоматические изменения

Без отдельного решения запрещено:

- добавление новых обязательных слоёв ядра;
- перенос экспериментальных моделей в канон;
- изменение границы CKS / KAT9I_OS;
- превращение исследования в архитектурный стандарт.

## Допустимое развитие

Любое изменение проходит путь:

```text
GAP (выявленный разрыв)
↓
Evidence (доказательство)
↓
Proposal (предложение)
↓
Decision (решение)
```
