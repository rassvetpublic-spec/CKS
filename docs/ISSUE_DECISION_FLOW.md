# Issue Decision Flow

## Goal

Connect GitHub collaboration events with CKS decision management.

## Flow

Issue
↓
Analysis
↓
Decision Record
↓
Evidence Collection
↓
Implementation
↓
QA
↓
Accepted Knowledge or Completed Task

## Rules

- Issues track work.
- Decisions track choices.
- Evidence tracks justification.
- Canon tracks stable knowledge.

No direct transition from Issue to Canon is allowed.
