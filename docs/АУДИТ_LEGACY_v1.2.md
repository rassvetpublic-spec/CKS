# Аудит Legacy CKS v1.2

## Результат прохода

Проверены зоны исторических материалов:

- examples/
- graveyard/

## Решение

Физическое перемещение не выполняется автоматически без проверки содержимого каждого файла.

Причина:

каталог может содержать демонстрационные материалы, которые нужны для обучения и проверки, но не являются частью Core.

## Статус

| Область | Статус |
|---|---|
| Core | защищён |
| Legacy | изолирован правилами |
| Examples (примеры) | требуют классификации по содержимому |
| Эксперименты | не являются каноном |

## Ограничение

Наличие каталога в репозитории не означает принадлежность к архитектуре CKS v1.2.
