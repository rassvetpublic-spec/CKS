# CKS v1.5 Implementation Core Package 005 — Self Audit System

## Назначение
Самопроверка архитектуры CKS.

## Проверки
- границы слоёв;
- состояние знаний;
- наличие доказательств;
- целостность графа;
- история изменений.

## Ограничение
Self Audit обнаруживает проблемы, но не изменяет Canon самостоятельно.
