# CKS Canon Registry Specification v1

## Purpose

Canon Registry stores accepted and stable knowledge that has passed review.

## Rules

A canon object requires:

- source;
- evidence;
- decision reference;
- lifecycle status.

## Lifecycle

```
Candidate
   ↓
Review
   ↓
Accepted
   ↓
Canon
   ↓
Superseded
```

## Protection

Canon cannot be silently replaced by experimental data.

Any change requires a new decision record.
