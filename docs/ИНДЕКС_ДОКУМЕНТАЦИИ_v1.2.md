## Правила языка документации

Основной язык документации — русский.

Английские термины допускаются только если они являются общепринятым названием технологии, формата или совместимости.

При использовании термин указывается с простым переводом:

```
Term (перевод на русский)
```

## Правило канона

Документация описывает только утверждённое состояние CKS.

Исследования, предложения и эксперименты хранятся отдельно и не изменяют канон без процедуры:

```
GAP → Evidence → Proposal → Decision
```
