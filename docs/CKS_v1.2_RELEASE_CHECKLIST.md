# CKS v1.2 — Release Checklist (финальный контроль)

## Статус

```yaml
version: CKS_v1.2
status: archived
architecture: stable
core: frozen
development: gap_driven
```

## Архитектура

- [x] Граница CKS и KAT9I_OS зафиксирована.
- [x] Core (ядро системы) не расширяется без подтверждённого GAP (выявленного разрыва).
- [x] Legacy (наследие) изолирован.
- [x] Research (исследование) отделено от канона.
- [x] Example (пример) не считается архитектурным решением.

## Слои

- [x] Core содержит утверждённые модели и правила.
- [x] Adapter (адаптер) работает только как слой обмена и преобразования.
- [x] GitHub используется как инфраструктура работы, а не как база знаний.
- [x] Workflow (процессы проверки) выполняют проверку, но не принимают архитектурные решения.

## Управление изменениями

Все архитектурные изменения проходят:

```text
GAP (выявленный разрыв)
↓
Evidence (доказательство)
↓
Proposal (предложение)
↓
Decision (решение)
↓
Minimal Change (минимальное изменение)
```

## Запреты CKS v1.2

Без нового GAP запрещено:

- расширять Core;
- переносить Research в Core;
- превращать Experiment (эксперимент) в Canon (канон);
- использовать Legacy как действующую спецификацию.

## Итог

CKS v1.2 находится в режиме стабильной закрытой архитектуры.

Следующая версия создаётся только через подтверждённые архитектурные разрывы, доказательства и решения.
