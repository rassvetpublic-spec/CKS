# CKS — система контекста и знаний

Независимая система работы с контекстом, знаниями, решениями, доказательствами и историей изменений.

## Статус CKS v1.2

```yaml
version: CKS_v1.2
status: archived
architecture: stable
core: frozen
development: gap_driven
```

## Граница системы

CKS не является исполнительной системой.

CKS отвечает за:

- контекст;
- знания;
- решения;
- доказательства;
- историю изменений.

KAT9I_OS отвечает за исполнение, рабочие процессы и операционные действия.

## Архитектурные части

- Core Engine (ядро системы);
- Context Split Modes (режимы разделения контекста);
- Knowledge Objects (объекты знаний);
- Decision System (система решений);
- Evidence Layer (слой доказательств);
- External Storage Adapters (внешние адаптеры хранения);
- Protocol Contracts (договоры обмена).

## Режимы работы

- SPLIT (разделение);
- AUDIT (аудит);
- REVIEW (проверка);
- RESEARCH (исследование);
- MIGRATION (перенос);
- CLEANUP (очистка);
- MERGE (объединение);
- CANON CHECK (проверка канона).

## Правила развития

1. Расширение ядра запрещено без подтверждённого GAP (выявленного разрыва).
2. Proposal (предложение) не является Decision (решением).
3. Experiment (эксперимент) не является Canon (каноном).
4. Исследовательские материалы не становятся частью архитектуры автоматически.

## Развитие после v1.2

Любое изменение проходит путь:

```
GAP (выявленный разрыв)
↓
Evidence (доказательство)
↓
Proposal (предложение)
↓
Decision (решение)
↓
Minimal Change (минимальное изменение)
```

CKS v1.2 находится в режиме стабильной закрытой архитектуры.
