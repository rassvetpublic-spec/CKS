# Карта изоляции Legacy (наследия)

## Цель

Не допустить смешивания исторических материалов с CKS v1.2 Core (ядром системы).

## Границы

```text
CKS v1.2 Core
    |
    | не зависит
    v
Legacy (наследие)
```

## Правила

1. Legacy доступен для анализа и восстановления истории.
2. Legacy не изменяет архитектуру.
3. Legacy не является источником новых правил без процедуры изменения.
4. Все изменения проходят через зарегистрированный GAP.

## План переноса

1. Найти исторический материал.
2. Определить категорию.
3. Переместить в Legacy или оставить в каноне.
4. Зафиксировать решение.
