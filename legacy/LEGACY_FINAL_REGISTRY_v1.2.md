# LEGACY_FINAL_REGISTRY_v1.2

## Назначение

Реестр фиксирует границы между текущим состоянием CKS v1.2 и историческими материалами.

## Правила классификации

| Категория | Значение |
|---|---|
| Core (ядро системы) | утверждённая архитектура CKS v1.2 |
| Decision (решение) | принятое изменение с подтверждением |
| Evidence (доказательство) | материалы подтверждения |
| Research (исследование) | проверка идей без статуса решения |
| Example (пример) | демонстрационные материалы |
| Legacy (наследие) | исторические материалы, старые версии, отвергнутые варианты |

## Изолированные зоны

- `graveyard/` — исторические материалы.
- `examples/graveyard/` — примеры исторических состояний.
- `examples/rejected_memory_dump/` — отвергнутые варианты.

## Неизменяемые правила

Legacy (наследие) не является частью Core (ядра системы).

Research (исследование) не становится Canon (каноном) автоматически.

Proposal (предложение) не является Decision (решением).

Изменение Core выполняется только через:

GAP (выявленный разрыв)
→ Evidence (доказательство)
→ Proposal (предложение)
→ Decision (решение)
→ Minimal Change (минимальное изменение)

## Статус

CKS v1.2:

- architecture: stable
- core: frozen
- development: gap_driven
