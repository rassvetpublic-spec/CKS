# Legacy (наследие)

Этот каталог предназначен для исторических материалов CKS.

Правила:

- материалы здесь не являются частью канона CKS v1.2;
- содержимое не изменяет архитектуру;
- перенос из legacy (наследие) в основную архитектуру возможен только через:

```
GAP (выявленный разрыв)
↓
Evidence (доказательство)
↓
Proposal (предложение)
↓
Decision (решение)
```

Legacy используется для сохранения истории, экспериментов и отвергнутых вариантов.
