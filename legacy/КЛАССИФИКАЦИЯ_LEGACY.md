# Классификация Legacy (наследия) CKS v1.2

## Назначение

Этот документ фиксирует правила отделения исторических материалов от стабильной архитектуры CKS v1.2.

## Категории материалов

| Категория | Назначение |
|---|---|
| Канон | утверждённое текущее состояние CKS |
| Legacy (наследие) | старые версии, исторические решения, устаревшие модели |
| Исследование | материалы для изучения без статуса решения |
| Удаление | дубликаты или материалы без ценности |

## Правило переноса

Материал не становится частью CKS v1.2 автоматически.

Возврат из Legacy возможен только через:

GAP (выявленный разрыв)
↓
Evidence (доказательство)
↓
Proposal (предложение)
↓
Decision (решение)
↓
Minimal Change (минимальное изменение)

## Первичная классификация

- graveyard (кладбище вариантов) → Legacy;
- examples (примеры) → проверка на ценность, не часть Core;
- reports (отчёты) → архив или доказательства по решению;
- старые схемы → Legacy до подтверждения актуальности.
