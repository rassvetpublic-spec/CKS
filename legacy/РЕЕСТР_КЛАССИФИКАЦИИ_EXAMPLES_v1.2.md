# Реестр классификации примеров CKS v1.2

## Назначение

Документ отделяет демонстрационные материалы от ядра CKS v1.2.

## Правило

Каталог `examples` не является частью Core (ядра системы).

Материалы оцениваются как:

- Канон — утверждённая архитектура.
- Legacy (наследие) — исторические материалы.
- Research (исследование) — проверка идей без статуса решения.
- Example (пример) — демонстрационный материал.

## Классификация

| Путь | Статус | Причина |
|---|---|---|
| examples/decision | пример | демонстрация записи решения |
| examples/knowledge | пример | демонстрация объекта знаний |
| examples/kat9i_os_import | исследование | проверка границы CKS / KAT9I_OS |
| examples/graveyard | Legacy | исторические отвергнутые материалы |
| examples/rejected_memory_dump | Legacy | отклонённые данные |
| examples/real_knowledge_trial | исследование | экспериментальная проверка |

## Ограничение

Ни один материал из `examples` не изменяет Core автоматически.

Возврат в архитектуру только через:

GAP (разрыв)
→ Evidence (доказательство)
→ Proposal (предложение)
→ Decision (решение)
