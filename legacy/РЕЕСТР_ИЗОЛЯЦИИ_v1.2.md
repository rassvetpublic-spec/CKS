# Реестр изоляции Legacy CKS v1.2

## Назначение

Этот документ фиксирует материалы, которые необходимо отделять от актуального состояния CKS v1.2.

## Текущая классификация

| Путь | Класс | Действие |
|---|---|---|
| graveyard/ | Legacy (наследие) | оставить в историческом архиве |
| examples/graveyard/ | Legacy (наследие) | не считать частью Core |
| examples/rejected_memory_dump/ | Legacy (наследие) | хранить как отвергнутый материал |
| examples/kat9i_os_import/ | исследование интеграции | проверять отдельно |
| examples/real_knowledge_trial/ | эксперимент | не включать в канон |
| examples/decision/ | пример | не является архитектурой |
| examples/knowledge/ | пример | не является хранилищем знаний CKS |

## Правило

Legacy (наследие), примеры и эксперименты не изменяют CKS v1.2.

Возврат любого материала выполняется только через:

GAP (разрыв)
→ Evidence (доказательство)
→ Proposal (предложение)
→ Decision (решение)
→ Minimal Change (минимальное изменение)
