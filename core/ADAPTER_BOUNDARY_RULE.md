# Adapter Boundary Rule

## Назначение

Этот документ фиксирует границу между CKS Core (ядро системы) и внешними адаптерами.

## Роль адаптера

Adapter (адаптер) может:

- читать утверждённые объекты CKS;
- преобразовывать внешние форматы;
- выполнять mapping (отображение) между системами;
- создавать Proposal (предложение) для рассмотрения.

## Запрещено

Adapter не может:

- изменять Core напрямую;
- создавать Decision (решение) без процедуры принятия;
- превращать внешний статус в знание CKS;
- обходить Evidence (доказательство).

## Цикл изменения

GAP (выявленный разрыв)
→ Evidence (доказательство)
→ Proposal (предложение)
→ Decision (решение)
→ изменение Core при необходимости

## Граница KAT9I_OS

CKS хранит знания, решения и доказательства.

Исполнение, процессы и рабочие действия остаются вне CKS.
