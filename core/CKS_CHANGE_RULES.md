# CKS v1.2 Change Rules

## Границы ответственности

CKS хранит знания и решения.

KAT9I_OS и исполнители работают через определённые протоколы.

## Правила изменений

- Новый объект должен соответствовать схеме.
- Значимые решения должны иметь Evidence.
- Реализация изменения должна ссылаться на Decision.
- Автоматические исполнители не изменяют канон без процесса проверки.
- Совет (Council) проверяет предложения, но не заменяет Decision Object.
