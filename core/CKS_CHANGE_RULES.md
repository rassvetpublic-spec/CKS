# Правила изменений CKS v1.2

## Границы ответственности

CKS хранит знания и решения.

KAT9I_OS и исполнители работают через определённые протоколы.

## Правила изменений

- Новый объект должен соответствовать схеме.
- Значимые решения должны иметь доказательство (Evidence).
- Реализация изменения должна ссылаться на решение (Decision).
- Автоматические исполнители не изменяют канон без процесса проверки.
- Совет (Council) проверяет предложения, но не заменяет решение (Decision Object).
