# Модель объектов CKS v1.2

## Назначение

CKS хранит контекст, решения и знания через связанные объекты.

## Основные объекты

- Контекст (Context) — исходная ситуация и ограничения.
- Предложение (Proposal) — вариант решения или направление проверки.
- Решение (Decision) — принятое решение и его обоснование.
- Доказательство (Evidence) — подтверждающие материалы.
- Изменение (Change) — реализованное изменение.
- Событие обучения (Learning Event) — полученный опыт и выводы.
- Знание (Knowledge) — закреплённое знание системы.
- Снимок состояния (Snapshot) — состояние системы для восстановления контекста.

## Связи

Контекст (Context) → Предложение (Proposal) → Решение (Decision) → Изменение (Change) → Результат → Событие обучения (Learning Event) → Знание (Knowledge) → Снимок состояния (Snapshot)

Решение (Decision) должно иметь связь с Доказательством (Evidence).

Изменение (Change) должно иметь связь с Решением (Decision).

## Правило

Объекты CKS являются источником знаний. Проект GitHub (GitHub Project) используется только для управления состоянием работы.
