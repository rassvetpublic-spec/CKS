# Жизненный цикл CKS v1.2

## Жизненный цикл объекта

1. Создано
2. Проверяется
3. Принято
4. Используется
5. Изменяется
6. Заменено
7. Архивировано

## Принципы

- Изменения ядра требуют решения.
- Схемы объектов должны иметь версии.
- История изменений сохраняется.
- Архив не удаляется без решения.

## Цель

Обеспечить восстановление контекста и причин появления решений.
