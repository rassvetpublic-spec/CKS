# CKS v1.2 Очередь работ

## A — критично

- объект решения (Decision Object);
- объект снимка состояния (Snapshot Object);
- связи объектов;
- проверка схем.

## B — развитие

- развитие Совета (Council);
- автоматические отчёты;
- интеграция с Проектом GitHub (GitHub Project);
- адаптеры.

## C — исследование

- распределённые исполнители;
- расширенный поиск знаний;
- автономное изменение системы.

## Правило приоритета

Сначала стабилизировать договоры и объекты, затем добавлять автоматизацию.
