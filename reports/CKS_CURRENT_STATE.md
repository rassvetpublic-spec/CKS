# Текущее состояние CKS

Версия: CKS v1.2 (начальная основа)

## Назначение

CKS — система хранения контекста, решений и знаний.

## Текущее состояние

Готово:

- архитектурное разделение слоёв;
- структура каталогов;
- базовые протоколы обмена;
- слой Совета (Council);
- подготовка жизненного цикла объектов.

## В работе

- формализация объектов;
- версии схем объектов;
- проверка связей;
- снимки состояния.

## Следующие шаги

1. Добавить схемы объектов.
2. Создать проверки связности.
3. Реализовать снимок состояния.
4. Подготовить слой обработки (Engine) после стабилизации договоров.
