# CKS Promotion Protocol

## Purpose

Определяет переход объекта знания из кандидата в подтверждённый слой CKS.

## Lifecycle

CANDIDATE → REVIEW → ACCEPTED → CANON

## Rules

- объект не становится каноном без доказательств;
- изменения канона требуют истории решения;
- экспериментальные идеи не заменяют существующий канон.
