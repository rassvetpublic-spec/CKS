# CKS + Obsidian

## Назначение

Корень Git-репозитория CKS можно открыть в Obsidian как Vault (хранилище Obsidian). Отдельная копия базы знаний не требуется.

Obsidian используется только как графическое и навигационное представление. Источники истины CKS остаются в утверждённых объектах, решениях, доказательствах, схемах и реестрах.

## Что поддерживается

- YAML frontmatter (метаданные Markdown-файла);
- `[[wikilinks]]` для связей объектов;
- теги;
- кластеры как метаданные;
- проекты как проекции;
- русские названия и описания;
- граф Obsidian;
- обратные ссылки;
- поиск;
- локальный граф отдельного объекта.

## Рекомендуемый способ

1. Открыть корень репозитория CKS в Obsidian через «Open folder as vault».
2. Производные Markdown-представления создавать командой:

```bash
python tools/cks_knowledge_runtime.py objects.json --obsidian-dir .
```

3. Генератор создаёт каталог `Знания/` и файл `CKS_Обзор.md`.
4. Файлы в `Знания/` являются производными представлениями и могут быть пересобраны.

## Важная граница

`Obsidian graph != SSOT`.

Граф Obsidian показывает связи, но не принимает решения, не повышает объект до Canon (канона) и не заменяет Evidence (доказательства).

## Технические поля

Имена технических YAML-полей сохраняются на английском для совместимости с кодом. Человеческие значения, заголовки, пояснения и представления — на русском согласно ADR-007.
