# KAT9I_OS Adapter v1

## Purpose

Adapter boundary between KAT9I_OS execution system and CKS knowledge system.

## Boundary

KAT9I_OS:
- execution
- workers
- workflows
- runtime state

CKS:
- knowledge
- decisions
- evidence
- canon lifecycle

## Exchange Rule

KAT9I_OS does not transfer internal memory. Only validated context packages and artifacts are exchanged.
